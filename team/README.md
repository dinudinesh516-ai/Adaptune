# Team photos

Drop each member's photo here, named after them (lower-case, spaces → hyphens):

- `vismai-shankar.jpg`
- `faizal.jpg`
- `jerin.jpg`

Any of .jpg / .jpeg / .png / .webp works. Portrait photos (about 4:5) look best; they're cropped to fit,
resized and converted to WebP automatically. Until a photo is added, a placeholder with initials is shown.
